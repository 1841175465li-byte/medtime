# 界面与交互

药记使用浅灰底色、白色卡片和绿色主要操作。界面分为“今天”“记录”“药品”三个页面。

- 今天：按早、中、晚展示服药安排，每个时段可独立开关闹钟和调整时间。
- 记录：展示用药时间线、每条记录的当次用量，以及各药累计记录次数。
- 药品：搜索药品库并添加到个人列表，随后设置频率、用量或名称。
- 设置：备份、闹钟权限、赞助待开放页面及免责声明。

时间选择采用小时和分钟两列独立滚轮。设置保存反馈约 1 秒；记录操作提供约 4 秒撤销窗口。免责声明允许小屏滚动阅读并返回设置，无首次启动确认门槛。

本目录三个 PNG 是 1.6.0 的 432×936 页面截图，使用空记录的独立预览环境。它们不表示任何真实个人的用药情况。界面还验证过 320、360 和桌面宽度。
