# 界面与交互

药记沿用浅灰底、白色卡片和绿色主要操作。页面为“今天”“记录”“药品”；1.7 增加空列表首次引导、药品扩展信息和提醒检查流程；1.7.1 将独立时间统一为点击打开的双列滑动弹窗。

- 今天：早、中、晚、睡前安排，药品下方显示独立时间，时段开关统一控制本时段。
- 药品：个人／药品库／已归档三个列表，可查找名称、规格、剂型，设置安排并暂停归档。
- 记录：保留当时药名、规格、剂型、用量和时间，累计次数按记录条数计算。
- 提醒设置：系统条件、立即试听、锁屏试响的实际结果确认。

welcome-v1.7.png 是 432×936 的全新空列表；schedule-v1.7.png 展示演示药品的独立时间与疗程表单。演示数据不会进入安装包。independent-time-v1.7.1.png 展示最新版的两列滑动时间弹窗；旧版图片保留为界面资料。

界面检查使用 Edge／Playwright，覆盖 320、360、432 和 1280 像素宽度。实际 Android 锁屏、声音和后台行为仍需设备验证。
